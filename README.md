# 🌱 Prediction of Evapotranspiration (ET) Rate using Machine Learning

## 📌 Project Overview

Evapotranspiration (ET) is a crucial parameter in agriculture as it represents the combined loss of water through evaporation from soil and transpiration from plants. Accurate prediction of ET helps farmers and planners optimize irrigation schedules and improve crop productivity.

This project focuses on predicting **Evapotranspiration (ET) rates** for a given location using **machine learning techniques** based on meteorological and environmental factors.

---

## 🎯 Objectives

* To analyze meteorological data affecting evapotranspiration
* To build a machine learning model that predicts ET rate accurately
* To assist in better irrigation planning and water resource management

---

## 🗂️ Dataset Description

The dataset used in this project contains approximately **20,000 records** with the following features:

* Maximum and minimum temperature
* Solar Radiation
* Wind Speed
* Humidity
* Rainfall

The target variable is:

* **Evapotranspiration (ET) Rate**
